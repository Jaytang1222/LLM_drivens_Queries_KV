# 本轮问题（comparative_refine_6.md §15）

## 1. 当前失败主要是模型选错、估计错误还是门控/调度损失？

**三者并存，主损失在 LLM 墙钟；门控挡住多数高估采纳。**

- 证据链已分离：九条 `llm_parse_status=ok`，原始提议几乎全为 `PROPOSE_P_T`（不被门控覆盖）。
- 门控拒绝 5 条（`gate_conservative_s`/`gate_negative_s`）；`llm_adopt` 仅 2 条（`ais_st_control_tiny`、`topk_st_3` → `P_T`）。
- 采纳两条的 **exec 变快**（20 vs 90；99 vs 137），但 plan≈LLM≈2–3.7 s，E2E 仍大负。
- 其余路径 `final_selection_source=cbo_parallel`：模型提议被拒或无效后执行 CBO，墙钟仍被 LLM 下界压住。

结论：不是“摘要把投机抹成 KEEP”的假象；本轮清楚看到 **模型偏好单一动作 + 估计偏乐观被门控挡住 + 即使采纳也被调用延迟淹没**。

## 2. 在线估计的哪个环节最需要执行反馈？

见 `feedback_calibration.md`：405 对残差 **MAE≈1331 ms**，全体上侧 **p95≈1128 ms**（本轮 `KART_CALIB_OVERESTIMATE_P95_MS=1128`）。  
正机会召回（S_pred≥200）仅 7/40，说明相对收益符号/幅度仍不稳。优先需要反馈的是 **联合过滤后候选规模与回表驱动的相对收益**，而非再加统一常数。线上 FastCost 特征误差尚未计入本残差。

## 3. 少量当前查询证据能否以更低成本替代大额保守惩罚？

**本轮未能验证。** `PROBE_JOINT_CANDIDATES` 已实现（预算 50 ms），但模型 **从未提出探测动作**（`t_probe_ms=0` / `probe_started` 全无）。  
因此不能声称“小探测可替代 ~1.1 s 余量”；只能报告：探测路径就绪，但 LLM 未进入该分支。合成侧也几乎总输出 `PROPOSE_P_T`（soft_ok 3/8）。

## 4. LLM 是否提出了固定策略不易找到的有效检查或候选？

**否。** 合成 format_ok=8/8，但 8/8 例中 7 次输出 `PROPOSE_P_T`（含无机会/负例）；库内九条同样高度单一。  
未观察到相对固定策略的额外信息增益；若存在 exec 改善，也来自确定性采纳 `P_T`，不能归因于“独特检查”。

## 5. 所有成本计入后，是否仍有可重复 E2E 净收益？

**否：0 胜 / 9 负**（同跑 CBO；Oracle 全过）。  
两条 `llm_adopt` 证明候选切换与安全验证通路可用，但计入 LLM 后无净胜。详见 `timing_plan_exec.md`。

## 6. 是否有证据支持进一步研究分区混合访问？

**尚无。** 未观测到区域路径优劣反转的探测证据；整查询切换也无 E2E 净胜。按 §10.3，**不进入分区实现**。
