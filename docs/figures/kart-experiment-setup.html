KART (ours · 默认) CBO RBO FullScan
基于 BeamSearch + Final 代价模型（cost_v2_rs_sched）选择 SafePlan；叠加 Dual Rewrite（离线已接纳规则 + 在线残差 LLM）；可选启用高级索引 XZ* / TShape / XZT。 Best-first / Beam 代价优化器；在经典索引（Time / Z-Order / Hash）与 FullScan 上做覆盖约束下的代价排序；当前对比臂关闭高级索引，且无 LLM 改写。 固定模板优先级：TZ → T → Z → H →（高级族）→ FULL；不做候选枚举与代价 argmin，仅按顺序取第一个通过验证的计划。 强制 P_FULL 全表扫描基线；无索引剪枝；用于 Oracle 对齐与上界延迟对照。

参数
beam_width max_candidates max_llm_calls cache query type
BeamSearch 宽度；控制 frontier 宽度。默认 3。 进入验证 / Final 的候选上限。默认 8。 单查询 LLM 调用预算；耗尽则 LLM_BUDGET 停搜。默认 6（规则臂为 0）。 冷/热缓存协议：cold（正式首轮）或 warm（warmup 后计时）。 空间/时空范围查询（SRQ / ST-Range）、相似度 Top-K（DTW / Frechet / Hausdorff）。默认以范围查询为主。
数据集 & 参数配置
数据集
T-Drive（manifest tdrive_v1_ready）：北京出租车轨迹快照，实验就绪集约 47,102 条轨迹；单机 HBase 默认数据集。

Query Workload：冻结 BoundIR + FullScanOracle。
· Simple：bound_ir_simple_v1（28 条；含纯时 / 纯空 / 时空 / Top-K）
· Complex：bound_ir_complex_v1（31 条；默认 E2E 主集，时空范围）
· 诊断旁路：ADV frag / mix / complex-diag（不并入主表，除非单独声明）

不支持：CD-Taxi、连续路径、连续 Fréchet、Quadtree（见 supported-semantics）。
